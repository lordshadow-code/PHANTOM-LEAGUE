RULEBOOK

Reglas claras.

Una clasificación transparente para toda la comunidad.

¿Cómo se calcula la clasificación?＋

Una victoria suma 3 puntos, un empate 1 y una derrota 0. Los desempates se resuelven por puntos, diferencia global de mapas, enfrentamiento directo entre los equipos igualados y diferencia de mapas en ese enfrentamiento. Si persiste el empate, se ordena por nombre.

¿Cómo registro un resultado?＋

Usa el panel para preparar el partido, descarga partidos.json y súbelo al repositorio. También puedes editar el archivo directamente en GitHub. Los cambios publicados se reflejan cuando la web vuelve a cargar los datos.

¿El panel publica automáticamente?＋

No. GitHub Pages es un alojamiento estático. Este panel genera archivos para que un colaborador autorizado los revise y confirme. No se guardan tokens de escritura ni contraseñas en el navegador.
